# Artistry Beauty Lounge demo

## Share with a client (recommended)

From the repo root:

```bash
./rebuilds/artistrybeautylounge.co.uk/deploy_pages.sh
```

Live URL: https://mysavvi.github.io/artistry-beauty-lounge-demo/

## Local preview

```bash
python3 rebuilds/artistrybeautylounge.co.uk/bundle_demo.py
cd rebuilds/artistrybeautylounge.co.uk/demo
python3 -m http.server 8765
```

Open http://localhost:8765/index.html
